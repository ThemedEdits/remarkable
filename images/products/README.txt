PRODUCT IMAGES FOLDER
=====================
Place your laptop images here following this naming convention:

laptop1.jpg    ← Main product image (maps to product id "p001")
laptop1b.jpg   ← Second gallery image
laptop1c.jpg   ← Third gallery image

laptop2.jpg    ← Product "p002" main image
laptop2b.jpg
laptop2c.jpg

... and so on.

Recommended:
- Size: 800x600px minimum
- Ratio: 4:3
- Format: JPG or WebP
- Quality: 80% compression is fine
